# Kinara Land Company Site

Website company profile PT Kinara Land Indonesia, dibangun terpisah dari aplikasi Rivere.

## Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Build produksi

```bash
npm run build
npm start
```

Stack: Next.js 15 App Router, TypeScript, Tailwind CSS, Framer Motion, GSAP ScrollTrigger, Lenis, dan `next/image`.
